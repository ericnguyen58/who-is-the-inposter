# Your own music (optional)

Put audio files here (`.mp3`, `.m4a`, `.ogg` or `.wav`):

| File name | When it plays |
|---|---|
| `lobby.mp3` | Loops on the lobby screen (both modes) until a game starts. Starts again after Reset or Back to lobby. |
| `vote.mp3` | Plays from the start during each 10-second Imposter vote, instead of the built-in music. |

- Restart is not needed: the scoreboard picks files up on its next update (for example when a player joins).
- Browsers only allow sound after the scoreboard page has been clicked once.
- Everything in this folder except this README is ignored by git, so your files are never pushed to GitHub.
- Only use music you have the right to play.
