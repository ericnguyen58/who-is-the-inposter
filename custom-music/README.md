# Your own vote music (optional)

Put an audio file here named `vote.mp3` (or `vote.m4a`, `vote.ogg`, `vote.wav`).
The scoreboard plays it from the start during each 10-second vote instead of the built-in music.

- Restart is not needed: the scoreboard picks it up on its next update (for example when a player joins).
- Everything in this folder except this README is ignored by git, so your file is never pushed to GitHub.
- Only use music you have the right to play.
